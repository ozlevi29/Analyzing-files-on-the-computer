# רופא המחשב

תוכנה למחשב Windows שמאבחנת למה המחשב איטי, מראה מה אפשר למחוק ומסבירה לכל קובץ ותיקייה אם בטוח למחוק אותם.

## הפעלה

1. צריך Python 3.12 ומעלה (בלי חבילות נוספות).
2. לחיצה כפולה על `start.bat`.
3. נפתח חלון. לוחצים **סרוק את המחשב**.

כדי לנקות גם תיקיות מערכת של Windows, כמו עדכונים ישנים וקבצים זמניים של המערכת, מפעילים את `start-as-admin.bat` במקום.

## מה התוכנה עושה

**למה המחשב איטי.** אחרי הסריקה מופיע דוח שמסביר כל סיבה לאיטיות, מהחשובה ביותר, עם צעדי טיפול. ליד כל צעד יש כפתור **טפל**.

**מה אפשר למחוק.** כל מיקום מוכר במחשב מוצג עם הגודל שלו ועם שלוש תשובות: מה זה, האם בטוח למחוק, ואיך מנקים. לכל פריט יש רמת בטיחות:

| תווית | משמעות |
|---|---|
| בטוח למחוק | המערכת או התוכנה יוצרות מחדש את מה שהן צריכות |
| בדוק לפני שמוחקים | אפשר למחוק, אבל יש מחיר קטן או שצריך לבדוק |
| לפנות רק דרך Windows | לא למחוק ידנית, רק בכלי הרשמי של Windows |
| לא למחוק | מוצג רק כדי להסביר למה התיקייה גדולה |

**קבצים ותיקיות גדולים.** סריקה מלאה של הכונן מציגה עץ של התיקיות הגדולות, רשימת קבצים מעל 500 MB עם הסבר לכל אחד, ותיקיות `node_modules` בפרויקטים.

**פרטי מערכת.** זיכרון, תוכנות שצורכות הכי הרבה, תוכנות שנפתחות עם המחשב, אנטי-וירוס, תקינות הדיסק ובדיקת רשת.

## בטיחות

- לפני **כל** פעולה מופיע חלון שמסביר מה יקרה, והפעולה מתבצעת רק אחרי אישור.
- הסריקה רק קוראת מידע. שום דבר לא נמחק בזמן סריקה.
- ניקוי מטמונים מדלג על קבצים שנמצאים בשימוש ועל קבצים זמניים מה-24 השעות האחרונות.
- קבצים אישיים לא נמחקים אוטומטית אף פעם. הם עוברים לסל המחזור רק אחרי אישור.
- ביטול הפעלה אוטומטית של תוכנה זהה ל"השבת" במנהל המשימות, ואפשר להחזיר משם.
- פקודות מערכת (כיבוי קובץ השינה, DISM) נפתחות בחלון נפרד עם בקשת אישור מנהל של Windows.
- השרת המקומי מאזין רק למחשב הזה ודורש מפתח אקראי שנוצר בכל הפעלה.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `app/rules.py` | מאגר הידע: מיקומים מוכרים, רמת בטיחות והסברים |
| `app/scanner.py` | מדידת גדלים, ניקוי, סל מחזור וסריקת כונן מלאה |
| `app/diagnostics.py` | בדיקות מערכת ובניית הדוח עם צעדי הטיפול |
| `app/main.py` | שרת מקומי שמחבר בין הממשק לפעולות |
| `app/static/` | הממשק (HTML, CSS, JavaScript) |

כדי להוסיף מיקום חדש לניקוי, מוסיפים רשומה לרשימה `RULES` בקובץ `app/rules.py`.
